# Луми — дизайн квартиры, визуальная модель и видеопрогулка

Готовый frontend-прототип Telegram Mini App. Можно опубликовать на GitHub Pages без собственного сервера.

## Что умеет

- **Планировка:** загрузка PNG/JPEG/WEBP как подложки; PDF (первая страница, при наличии доступа к PDF.js CDN). Создание прямоугольных комнат на плане, перемещение, названия, ширина, длина и высота потолков. **Автоматическое распознавание стен на фотографии не реализовано** — размеры вводятся или обводятся вручную.
- **3D-студия:** браузерная псевдофотореалистичная 3D-визуализация на Canvas с перспективной камерой; изменения размеров, положения мебели и материалов отображаются сразу. Переключатель «С мебелью / без мебели».
- **Мебель и техника:** каталог типов предметов, габариты в метрах, координаты X/Y, стоимость, возможность сохранять артикул, магазин и ссылку; таблица общей сметы.
- **Единый интерьер:** семь стилей: скандинавский, современный, джапанди, лофт, минимализм, бохо и неоклассика. Применение единого стиля ко всей квартире.
- **Мудборды:** картинки для каждой комнаты; программа извлекает ориентировочную цветовую палитру и переносит её на стены, пол и мебель. «Собрать палитру из мудбордов» — согласование цвета по квартире. Это алгоритмическая палитра, а не генеративная AI-фотореалистичная реконструкция.
- **Видео-прогулка:** кнопка «Начать видео-обзор» запускает движение камеры от входной двери через коридор и отдельные комнаты; есть пауза, перезапуск и остановка. Кнопка «Записать видео» скачивает WebM, если браузер поддерживает `canvas.captureStream` и `MediaRecorder`. Для iOS Telegram WebView запись может быть недоступна: просмотр маршрута остаётся доступным.
- **Похожие товары:** кнопка поиска на рынке показывает внешние ссылки на «Петрович», «Яндекс Маркет» и Ozon. Для тумб под раковину и светильника есть несколько реальных примеров кодов товаров «Петровича», найденных в публичном каталоге, но проверка актуальной цены/наличия онлайн не реализована.
- **PDF:** экспорт A4 через собственный генератор PDF: изображение визуализации, 2D-план, общая сумма, отдельные итоги по мебели и технике, перечень позиций с введёнными артикулами. **Чистовая отделка и ремонт не входят.**
- **Файлы проекта:** локальное автосохранение в браузере и ручное резервное копирование/восстановление JSON.

## Публикация на GitHub Pages

1. Создай новый **публичный** репозиторий, например `lumi-home`.
2. Распакуй ZIP. В корень репозитория загрузить именно `index.html`, `app.js`, `styles.css`, папку `assets`, `.nojekyll` и `README.md` — не сам архив и не содержащую их дополнительную папку.
3. GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
4. Найди опубликованную ссылку вида `https://USERNAME.github.io/lumi-home/`. Она должна открывать сайт.
5. В Telegram открой @BotFather, создавай **отдельного бота** для Луми (`/newbot`) или оформи отдельное Mini App (`/newapp`) и добавь опубликованный HTTPS URL. `/setmenubutton` позволяет дать кнопку запуска из меню бота.
6. Если у тебя уже есть бот сказки «Мурчалкинс», не заменяй его Web App URL при настройке нового приложения, чтобы не сломать сказку.

## Зависимости и ограничения

- Основные страницы, 3D, PDF и видеопрогулка работают без внешних JavaScript-библиотек. Для загрузки PDF-планировки используется CDN PDF.js; если он недоступен, загрузи PNG/JPG или скриншот плана.
- Сохранение только в текущем браузере (`localStorage`). Для сохранности регулярно выгружай `.json`; между устройствами синхронизации нет.
- 3D-визуализация — облегчённый геометрический прототип, а не точный BIM/CAD и не профессиональный фотореалистичный рендер. При редактировании схемы пользователь отвечает за дверные проёмы, пересечения мебели, масштаб и геометрию.
- Встроенный алгоритм видеомаршрута удобнее всего работает на исходном примере с центральной прихожей. После кардинальной перепланировки маршрут может требовать адаптации и проходить сквозь стены.
- Онлайн-поиск точных товарных аналогов, автоматическая актуализация цен, настоящая генеративная AI-визуализация и серверная обработка планов требуют отдельной интеграции с API/бэкендом.
- Внешние ссылки и цены не являются рекомендацией купить товар и требуют проверки у продавца.
